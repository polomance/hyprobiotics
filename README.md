# 김동건 — 프로바이오틱스 제품화 파트너 소개 페이지

이력서(김동건_이력서.docx) 원문과 사용자가 제공한 결과 링크를 바탕으로 만든 **한 장짜리 소개 페이지**입니다.
컨설팅이 필요한 동종업계 스타트업·중소기업 재직자를 독자로 가정했습니다.

## 페이지 구성 (요청하신 순서 그대로)

| 순서 | 섹션 | 앵커 | 내용 |
| --- | --- | --- | --- |
| 1 | 한 줄 정의 | `#top` / `.hero` | "AI + 프로바이오틱스 제조" — 균주 연구부터 GMP 공장, 브랜드 런칭까지 잇는 13년 차 식품 R&D 엔지니어 |
| 2 | 이런 문제를 풉니다 | `#problems` | Lab→Plant 스케일업, 원료 편차, GMP·인허가, OEM 품질, 카테고리/BM 부재 — 5개 문제 |
| 3 | 성과 | `#results` | 3개 (국내 최초 / 13년 차 3개 부문 / GMP 공장 증축) |
| 4 | 제공하는 일 | `#offer` | 첫 제안 1개: **프로바이오틱스 제품화 경로 진단** |
| 5 | 최근 글 | `#writing` | 글 제목 3개 |
| 6 | 연락하기 | `#contact` | 이메일 + 링크드인 |

헤더 우측 상단에 `커피챗 신청` 버튼 → `mailto:melo_mance@kakao.com` (제목/본문 프리필).
전화번호와 주소는 의도적으로 넣지 않았습니다.

## 파일

- `index.html` — 전체 마크업(시맨틱 header/main/section/footer), 인라인 스타일 없음
- `css/style.css` — 흰 바탕 + 강조색 1개(`--accent: #0e7c66`), 모바일 우선 반응형
- `js/main.js` — 헤더 스크롤 그림자, 섹션 페이드 인 (prefers-reduced-motion 존중)
- 외부 의존: Google Fonts Noto Sans KR (CDN), 그 외 라이브러리/이미지 없음

## 데이터 근거와 제약

- 성과 숫자·사실은 **이력서 원문에 있는 것만** 사용: 13년 차(2013.12 입사, 재직 중), 3개 부문(R&BD/생산/마케팅),
  국내 최초 식후혈당 상승 억제 유산균 음료 '케어온 당밸런스' 런칭, GMP 공장 증축·인증, 주요 설비 도입, 품질관리인 수행.
- 고객사 이름·후기·수치 실적(매출, 생균수 %, CAPA 등)은 이력서에 없으므로 **창작하지 않았습니다.**
- 인물 표기: 이력서는 김동건, 연락 이메일/링크드인은 사용자가 지정한 `melo_mance@kakao.com`, `www.linkedin.com/in/hyprobiotics` 값 그대로 사용했습니다.

### 미해결 / 확인 필요

1. **결과 링크 2개 본문 미확인** — `genspark.ai/agents?id=7cd09adf…`(STEP 2), `…202104d1…`(STEP 3)은
   비로그인 요청 시 로그인 페이지로 302 → 403이 반환되어 본문 열람이 불가했습니다.
   이에 따라 `제공하는 일`(STEP 2 첫 제안)과 `최근 글` 제목 3개(STEP 3 첫 주 캘린더)는
   **이력서 근거로 작성한 초안**입니다. 원문 문구가 있으면 그대로 교체하는 편이 좋습니다.
2. 연락처(이메일 `melo_mance@kakao.com`, 링크드인 `www.linkedin.com/in/hyprobiotics`)는 확정된 값으로 반영 완료.

## 로컬 확인

`index.html`을 브라우저로 열면 됩니다. 별도 빌드·서버·데이터베이스 없음(정적 파일만, 테이블/저장소 사용 안 함).

## 배포

- 시도: Hosted Deploy (Workers for Platforms) → `membership_required` (`plus_or_higher`)로 중단.
  현재 멤버십으로는 에이전트 배포가 불가하여 **아직 라이브 URL이 없습니다.** 재시도하지 않았습니다.
- 대안: 편집기 상단 **Publish 탭**에서 발행하면 라이브 주소가 발급됩니다(Plus 이상 필요).
- Plus 이상으로 업그레이드한 뒤에는 이 프로젝트에서 Hosted Deploy를 다시 요청하면 됩니다.
